# LBL AutoFlow Roadmap

## Phase 1 - Completed / Foundation

Core system foundation:

- Orders Dashboard
- Customer CRM
- Kitchen Queue
- Invoice Generator
- Corporate Leads CRM
- WhatsApp Templates
- Workflow Status Tracking
- Supabase Database
- Vercel Deployment

Goal:
Build a working bakery CRM foundation for daily operations.

---

## Phase 2 - Current Focus

Priority:
Improve operational stability, staff clarity, and sales workflow.

Focus areas:

1. Orders Dashboard
   - Cleaner order cards
   - Better filters
   - Clear payment and kitchen status
   - Safe edit order flow

2. Invoice System
   - Sequential invoice number
   - Clean invoice layout
   - Order-to-invoice sync
   - Customer total spend sync

3. Kitchen Queue
   - Active orders only
   - Completed orders collapsed by default
   - Clear production status
   - Avoid staff confusion when order volume grows

4. Corporate Leads CRM
   - Lead scoring
   - Lead priority: Hot / Warm / Cold
   - Follow-up status
   - WhatsApp outreach templates
   - Corporate gifting pipeline

5. WhatsApp CRM
   - Order confirmation
   - Payment reminder
   - Follow-up message
   - Corporate lead opening message

## Product Manager Rule

Before building any new feature, check:

1. Does it increase sales?
2. Does it save staff time?
3. Does it reduce order mistakes?
4. Does it improve customer experience?
5. Is Phase 2 already stable?

If Phase 2 is not stable, do not jump into Phase 3.
